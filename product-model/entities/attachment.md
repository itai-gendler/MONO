# Attachment

A local file attached to one item, individually downloadable and removable.

## Information kept

- **Name** — Original file name.
- **Media type** — The file type used to distinguish images.
- **Size** — File size.
- **Contents** — The attached file’s local contents.
- **Added at** — When it was attached.
